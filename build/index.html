Zone Controls

Water a whole zone - its valves open one at a time, in order.

Valve Controls

Tap a valve to toggle it open or closed, or Quick Water for a timed 30-second run. Valves always run one at a time. Valve setup (pins, names, flow meters) lives in the GPIO Pin Map card.

Moisture Readings

Live wetness per zone. Zones are set up in the Watering Zones card.

Moisture History

Percent moisture per zone, one reading per minute (about the last 3 hours). Hover the chart for details. History resets on reboot.

Environment

Optional extra sensors. An AHT20+BMP280 temp/humidity/pressure board plugs into the same I2C bus as the ADS1115 (auto-detected at boot - just wire it and reboot). An LM393 rain sensor's DO pin goes to any free GPIO - assign it in the pin map.

Watering Zones

Each zone is one soil moisture sensor at a spot in your garden/planter. When a zone reads drier than its "Dry below" threshold, it opens its assigned valve(s) one at a time, each for that zone's "Water for" run time - then waits for the soak period (Watering Settings), re-reads the sensor, and waters again if still below the "Water until" target, up to the max cycles cap. Once done, the zone waits out the cooldowns before it can re-trigger. Changes here apply immediately, no reboot.

Watering Schedules

Program as many watering times per day as you like. Tap the time to change it. Each schedule can target valves directly and/or whole zones (a zone runs whatever valves it's mapped to when the schedule fires) - everything opens one at a time, in order, for the set duration.

Watering Settings

Global behavior for automatic (moisture-triggered) watering. Each zone sets its own run time in Watering Zones; the default below covers the per-valve Trigger Watering button and any zone without its own.

GPIO Pin Map

Click any pin to see what it does, or to assign a free one. Solenoid valves and flow meters live directly on a GPIO pin. Moisture sensors don't - they wire into the ADS1115 board's 4 channels (assigned to zones in the Watering Zones card above), and the ADS1115 itself talks to the ESP32 over 2 shared I2C pins. Changes here reboot the ESP32 to take effect.

GPIOStatusAssigned to
Amber rows are boot-strapping pins - assignable, but read the warning when you click one. Red rows are the SPI flash and USB serial pins - never assignable. Greyed pins aren't on the WROOM-32 board. Input-only pins (34/35/36/39) can host a flow meter but not a valve.
Update Code

Drag .mpy, .py or .html files here (or click to browse) to update the firmware without Thonny - this includes index.html, the dashboard page itself. Normal updates are the .mpy files from the build folder; uploading a module as .py or .mpy automatically deletes its counterpart so the old copy can never shadow the new one. Reboot afterward to apply.

WiFi

Saved network: -. If WiFi stays down for 5 minutes, the planter opens a rescue hotspot ("Planter-Setup-xxxx") while watering keeps running - join it from any device and this dashboard is at http://192.168.4.1, where you can fix the network below. Changing WiFi reboots the ESP32.

Config Backup

Download this device's full configuration (zones, valves, pin map, schedules, settings - everything except WiFi) as a file, or restore one. Restoring replaces the current config and reboots. Handy for backups, or for loading a preset onto a fresh kit.
